# CloudVandana CRM Application

## Project Overview
A web-based CRM application integrated with Salesforce to manage business records using a React frontend and Node.js backend.

## Live Application
https://cloudvandana-frontend-ac16.onrender.com

## Backend URL
https://cloudvandana-crm-2hoa.onrender.com

## GitHub Repository
https://github.com/indrasena1234/Cloudvandana-crm

## Technologies Used
- React.js
- Node.js
- Express.js
- Salesforce
- JSforce
- JavaScript
- HTML
- CSS

## Features
- Salesforce OAuth 2.0 Authentication
- Manage Account records
- Manage Opportunity records
- Manage Lead records
- Manage Contact records
- Manage Case records
- Create, Read, Update and Delete (CRUD)
- Pagination (20 records per page)
- Responsive user interface

## How to Run Locally

### Backend
1. Open the server folder.
2. Run `npm install`.
3. Create a `.env` file with Salesforce credentials.
4. Run `npm start`.

### Frontend
1. Open the project root folder.
2. Run `npm install`.
3. Run `npm run dev`.

## Deployment
- Frontend hosted on Render Static Site.
- Backend hosted on Render Web Service.

## Security
Salesforce credentials are stored in the `.env` file.
Never upload the `.env` file or expose Salesforce secrets publicly.
